# Soma dos elementos de um array

**Status: planejamento — implementação ainda não iniciada.**

Repositório de estudo de [José Carlos](https://github.com/carlos0ff), organizado a partir da [seleção de desafios de Matheus Leandro](https://www.matheusleandro.com.br/desafios).

## Objetivo

Implementar uma função que percorra uma coleção de inteiros e devolva o total de seus valores.

## Regras

- Aceitar um array de números inteiros.
- Retornar um único resultado numérico.
- Retornar zero para uma entrada vazia.
- Realizar a acumulação manualmente, sem `reduce` ou funções prontas de soma.

## Casos de referência

| Entrada | Saída esperada |
| --- | --- |
| `[2, 4, 6]` | `12` |
| `[-3, 1]` | `-2` |
| `[]` | `0` |
| `[0]` | `0` |
